# 🚀 Gemini CLI 快速速查指南（Cheat Sheet）

## 🧩 基本命令

### 运行一次性指令

```bash
gemini "你好，介绍一下你自己？"
```

### 指定模型

```bash
gemini --model gemini-2.5-flash "Explain quantum computing in simple terms"
```

### 进入交互模式

```bash
gemini interactive
```

退出： `Ctrl+C`

---

# 📌 常用选项

| 参数              | 作用               | 示例                       |
| --------------- | ---------------- | ------------------------ |
| `--model`       | 指定模型             | `--model gemini-2.5-pro` |
| `--temperature` | 控制随机性            | `--temperature 0.2`      |
| `--top_k`       | 控制采样范围           | `--top_k 40`             |
| `--top_p`       | nucleus sampling | `--top_p 0.9`            |
| `--file`        | 读取文件作为输入         | `--file input.txt`       |
| `--json`        | 输出 JSON 格式       | `--json`                 |
| `--stream`      | 流式输出             | `--stream`               |
| `--output`      | 写入到文件            | `--output result.md`     |

# 📂 处理文件

### 上传文件并让 AI 分析

```bash
gemini --file notes.pdf "Summarize the key points"
```

### 写结果到文件

```bash
gemini "生成一篇300字的AI简介" --output ai.md
```

---

# 🛠️ 代码生成常用模板

### 生成代码

```bash
gemini "用 Rust 写一个 TCP echo server"
```

### 解释代码

```bash
gemini --file server.py "解释这段代码"
```

### 修复代码

```bash
gemini --file app.js "找出 bug 并修复"
```

---

# 🧪 高级参数

### 使用系统提示（system prompt）

```bash
gemini --system "你是一个专业 Linux 管理员" \
       "帮我写一个crontab自动备份脚本"
```

### 安全模式（无内容过滤）

> *如果 CLI 支持，你可以使用*

```bash
gemini --safety-level none "…"
```

### 以 JSON 格式返回结构化输出

```bash
gemini --json "输出一个 JSON，其中包含 title/content 字段"
```

---

# 🧠 查看可用模型

### 列出 CLI 支持的模型

```bash
gemini models list
```

### 查看当前使用的模型

```
/model
```

（在 interactive 模式下）

# 🌐 网络代理支持

如需通过代理使用 CLI（例如科学上网）：

```bash
set HTTPS_PROXY=http://127.0.0.1:7890
set HTTP_PROXY=http://127.0.0.1:7890
```

或在 Linux/macOS：

```bash
export HTTPS_PROXY=http://127.0.0.1:7890
export HTTP_PROXY=http://127.0.0.1:7890
```

# 🎯 常用示例集合

### 总结 / 翻译

```bash
gemini "Summarize the following:\n<内容>"
gemini "Translate to Chinese:\n<text>"
```

### 生成图片说明/CSS/设计文案

```bash
gemini "给我生成一个博客首页布局的 TailwindCSS 代码"
```

### 大文件分析（依赖模型支持）

```bash
gemini --file report.docx "提取重要结论"
```

# 🔍 快速参考：推荐模型选择

| 场景            | 推荐模型                          |
| ------------- | ----------------------------- |
| 速度最快、便宜       | `gemini-2.5-flash`            |
| 代码 + 推理 + 多模态 | `gemini-2.5-pro`              |
| 分析大文件 / 长文档   | `gemini-1.5-pro`              |
| 简单对话 / 快速任务   | `gemini-1.5-flash`            |
| 极简快速任务        | `gemini-2.5-flash-lite`（如果可用） |
