# 端到端集成测试需求

## 概述
端到端集成测试验证客户端与后端的完整交互流程，确保整个系统作为一个整体正常工作。

## 测试范围

### 1. 认证流程测试
- 1.1 用户注册 → 登录 → 获取用户信息 → 登出
- 1.2 令牌刷新流程
- 1.3 密码修改后旧令牌失效
- 1.4 并发登录处理

### 2. 消息流程测试
- 2.1 WebSocket 连接建立
- 2.2 发送私聊消息 → 接收确认
- 2.3 发送群聊消息 → 群成员接收
- 2.4 离线消息同步
- 2.5 消息去重验证

### 3. 群组流程测试
- 3.1 创建群组 → 邀请成员 → 成员加入
- 3.2 群组权限验证（群主/管理员/成员）
- 3.3 邀请码流程
- 3.4 成员管理（踢出/禁言/封禁）

### 4. AI Agent 流程测试
- 4.1 创建 AI Agent → 配置人设
- 4.2 触发 AI 响应（@提及）
- 4.3 AI Agent 统计数据

### 5. 媒体流程测试
- 5.1 图片上传 → 获取 URL
- 5.2 文件去重验证
- 5.3 缩略图生成

## 测试环境要求
- 后端服务运行在 localhost:8080
- PostgreSQL 数据库可用
- Redis 服务可用
- 测试数据隔离（使用事务回滚）
