# Security Policy

## Status

This project is **archived** (2026-11-02) and is not maintained. No security fixes, updates, or support will be provided.

Do not deploy this project to production or expose it to the public internet.

## Reporting

We do not accept vulnerability reports because there is no maintainer to address them.

## Credentials

Development credentials (API keys, JWT secrets) were exposed in this project's pre-archive Git history and public mirrors. They must be treated as compromised and revoked/rotated.

The published Git history has been rewritten to remove those values, but this does **not** make any previously exposed credential safe to reuse.
