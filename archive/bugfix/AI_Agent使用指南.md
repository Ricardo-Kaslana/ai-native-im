# AI Agent 使用指南

## 功能概述

AI Agent 是一个智能助手系统，可以为群组添加 AI 机器人，自动回复消息并提供帮助。

## 如何访问 AI Agent

### 方法 1：从群组聊天界面（推荐）

1. 打开任意群组聊天
2. 点击右上角的 **ℹ️ 信息图标**
3. 在群组信息页面，找到 **🤖 AI 助手** 选项
4. 点击进入 AI Agent 管理界面

### 方法 2：从群组列表

1. 进入群组列表
2. 点击群组进入聊天界面
3. 按照方法 1 的步骤操作

## AI Agent 功能

### 1. 创建 AI Agent

如果群组还没有 AI Agent，你会看到创建界面：

- **名称**：给 AI 助手起个名字
- **触发关键词**：设置哪些关键词会触发 AI 回复（例如：@AI、帮助、问题）
- **个性设置**：
  - **毒舌程度** (0-10)：控制 AI 的幽默和讽刺程度
  - **热情度** (0-10)：控制 AI 的友好和积极程度
  - **回复风格**：正式、友好、幽默等
  - **自定义提示词**：自定义 AI 的行为和回复风格

### 2. 管理 AI Agent

创建后，你可以：

- **查看统计信息**：
  - 总消息数
  - 总回复数
  - 响应率
  - 触发关键词统计

- **编辑个性**：调整 AI 的性格和回复风格

- **启用/禁用**：临时关闭或开启 AI Agent

- **删除 Agent**：永久删除 AI Agent

### 3. AI Agent 工作原理

1. **触发机制**：
   - 当消息包含设置的触发关键词时
   - AI Agent 会自动分析消息内容
   - 根据个性设置生成回复

2. **回复特点**：
   - 根据毒舌程度调整语气
   - 根据热情度调整积极性
   - 遵循设置的回复风格
   - 使用自定义提示词作为基础

## 使用场景

### 1. 客服助手
- 设置触发词：帮助、问题、咨询
- 风格：正式、热情度高
- 用途：自动回答常见问题

### 2. 娱乐机器人
- 设置触发词：笑话、段子、娱乐
- 风格：幽默、毒舌程度中等
- 用途：活跃群组气氛

### 3. 知识助手
- 设置触发词：@AI、请教、学习
- 风格：正式、热情度中等
- 用途：提供知识和建议

## 注意事项

1. **权限要求**：
   - 只有群主和管理员可以创建和管理 AI Agent
   - 所有成员都可以触发 AI Agent

2. **触发关键词**：
   - 建议设置 3-5 个关键词
   - 避免使用过于常见的词（如"的"、"是"）
   - 可以使用 @ 符号（如 @AI）

3. **个性设置**：
   - 毒舌程度过高可能导致不友好的回复
   - 建议从中等值开始调整
   - 可以随时修改个性设置

4. **性能考虑**：
   - AI Agent 使用 OpenAI API
   - 回复可能需要几秒钟
   - 避免设置过多触发词以减少不必要的调用

## 技术实现

### 后端 API

- `POST /ai-agents` - 创建 AI Agent
- `GET /ai-agents/group/:group_id` - 获取群组的 AI Agent
- `PUT /ai-agents/:id/personality` - 更新个性设置
- `DELETE /ai-agents/:id` - 删除 AI Agent
- `GET /ai-agents/:id/stats` - 获取统计信息

### 客户端界面

- `AIAgentScreen` - AI Agent 管理界面
- `GroupInfoScreen` - 群组信息页面（包含 AI Agent 入口）
- `ChatScreen` - 聊天界面（新增群组信息按钮）

## 故障排除

### 问题：找不到 AI Agent 入口

**解决方案**：
1. 确保你在群组聊天界面（不是私聊）
2. 查看右上角是否有信息图标（ℹ️）
3. 如果没有，尝试重启应用

### 问题：无法创建 AI Agent

**解决方案**：
1. 检查你是否是群主或管理员
2. 确保网络连接正常
3. 查看服务器日志是否有错误

### 问题：AI Agent 不回复

**解决方案**：
1. 检查 AI Agent 是否已启用
2. 确认消息包含触发关键词
3. 查看后端日志确认 OpenAI API 是否正常
