# 问题记录和解决方案归档

本目录包含项目开发过程中遇到的问题和解决方案记录。

## 目录结构

### 重要文档
- `WINDOWS_QUICK_START.md` - Windows 快速开始指南
- `WINDOWS_SETUP.md` - Windows 详细设置指南
- `Windows部署文档索引.md` - 部署文档索引
- `AI_Agent使用指南.md` - AI Agent 使用说明

### 问题修复记录
- `AI_Agent_*.md` - AI Agent 相关问题修复
- `WebSocket*.md` - WebSocket 相关问题
- `群聊*.md` - 群聊功能问题
- `消息*.md` - 消息相关问题

### 临时脚本 (可删除)
- `*.bat` - Windows 批处理脚本 (开发调试用)
- `*.txt` - 临时状态记录

## 注意
大部分 .bat 和 .txt 文件是开发过程中的临时文件，可以安全删除。
重要的问题解决方案已整合到主文档中。
