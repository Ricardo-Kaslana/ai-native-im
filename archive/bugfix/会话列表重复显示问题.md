# 会话列表重复显示问题

## 状态：✅ 已解决

## 问题描述

客户端消息页面会将同一群组或与同一人的会话重复显示。

## 根本原因

`conversationsProvider` 从两个数据源获取会话：
1. `/conversations` API - 返回所有会话（包括私聊和群组）
2. `/groups` API - 返回用户加入的所有群组

由于群组的 `group_id` 被直接用作 `conversation_id`（见 `sync_group_conversations.sql`），两个 API 返回的群组数据使用相同的 ID。但原来的代码直接合并两个列表而没有去重，导致同一个群组出现两次。

```dart
// 原来的代码 - 没有去重
final allConversations = [...privateConversations, ...groupConversations];
```

## 解决方案

使用 `Map<String, Conversation>` 按 ID 去重：

```dart
// 使用 Map 按 ID 去重
final conversationMap = <String, Conversation>{};

// 先添加 API 会话（数据更完整，包含参与者信息）
for (final conv in apiConversations) {
  conversationMap[conv.id] = conv;
}

// 再添加群组会话（仅当不存在时）
for (final group in groups) {
  if (!conversationMap.containsKey(group.id)) {
    conversationMap[group.id] = Conversation(...);
  }
}

// 转换为列表并排序
final allConversations = conversationMap.values.toList();
```

### 其他改进

1. 为 `ListView.builder` 中的每个 item 添加 `ValueKey`：
```dart
return ConversationListItem(
  key: ValueKey(conversation.id),
  conversation: conversation,
  ...
);
```

2. 更新了 provider 命名和注释，使其更准确：
   - `_privateConversationsProvider` → `_apiConversationsProvider`
   - 更新注释说明该 provider 返回所有会话类型

## 修改的文件

- `client/lib/presentation/providers/conversation_provider.dart` - 添加去重逻辑
- `client/lib/presentation/screens/messages/conversation_list_screen.dart` - 添加 ValueKey

## 数据流程

```
conversationsProvider
    ├── _apiConversationsProvider (从 /conversations API)
    │   └── 返回所有会话（私聊 + 群组）
    │
    └── groupsProvider (从 /groups API)
        └── 返回用户的群组
        
    ↓ 使用 Map 按 ID 去重
    ↓ API 会话优先（数据更完整）
    ↓ 按最后活动时间排序
    
    → 返回去重后的会话列表
```

## 验证方法

1. 重新启动客户端
2. 查看消息列表
3. 确认每个会话只显示一次
4. 创建新群组或私聊，确认不会重复显示
