# 消息发送和显示问题修复

## 问题概述

在消息系统重构后，出现了多个消息发送和显示相关的问题。

## 问题1: 数据库 updateMessage 方法错误

### 错误信息
```
InvalidDataException: Sorry, MessagesCompanion(...) cannot be used because:
• conversationId: This value was required, but isn't present
• senderId: This value was required, but isn't present
• type: This value was required, but isn't present
• content: This value was required, but isn't present
• createdAt: This value was required, but isn't present
```

### 原因
`database.dart` 中的 `updateMessage` 方法使用了 `replace()` 方法，该方法要求提供所有必填字段。

### 修复
将 `replace()` 改为 `update().write()`，只更新指定的字段：

```dart
// 修复前
await into(messages).replace(companion);

// 修复后
await (update(messages)..where((m) => m.id.equals(id))).write(companion);
```

- `client/lib/data/local/database.dart`

## 问题2: 消息重复显示

### 现象
- 发送消息后显示两条相同的消息
- 接收消息也显示两条
- 退出重进后变为一条

### 原因
1. Provider 使用 `ref.watch` 导致重复构建和加载
2. 服务器回显消息导致重复
3. 状态更新依赖 stream 而不是直接更新

### 修复
1. 将 `ref.watch` 改为 `ref.read` 避免重复构建
2. 添加重复检测逻辑（基于内容 + 发送者 + 2秒时间窗口）
3. 直接调用 `_updateMessageStatusInState()` 和 `_addMessageToState()` 更新 UI

```dart
// 重复检测
final isDuplicate = state.any((m) => 
  m.senderId == message.senderId &&
  m.content == message.content &&
  m.createdAt.difference(message.createdAt).abs() < const Duration(seconds: 2)
);

if (isDuplicate) {
  print('🔄 Skipping duplicate message: ${message.id}');
  return;
}
```

- `client/lib/presentation/providers/chat_provider.dart`

## 问题3: 消息状态一直显示"发送中"

### 现象
消息发送后状态一直是 sending，不会变成 sent

### 原因
状态更新依赖 stream 监听，但 stream 可能没有正确触发

### 修复
发送成功后直接调用 `_updateMessageStatusInState()` 更新 UI 状态：

```dart
// 发送成功后直接更新状态
_updateMessageStatusInState(message.id, MessageDeliveryStatus.sent);
```

- `client/lib/presentation/providers/chat_provider.dart`

## 问题4: 接收消息不实时显示

### 现象
收到的消息需要退出重进才能看到

### 原因
消息持久化后没有直接更新 UI 状态

### 修复
在 `_handleIncomingMessage` 中，持久化后直接调用 `_addMessageToState()`:

```dart
Future<void> _handleIncomingMessage(Message message) async {
  if (message.conversationId != conversationId) return;
  
  try {
    // 1. 先持久化到数据库
    await persistenceService.persistIncomingMessage(message);
    // 2. 立即更新 UI
    _addMessageToState(message);
  } catch (e) {
    // 降级处理：直接显示在 UI
    _addMessageToState(message);
  }
}
```

## 问题5: AI Agent 消息不显示

### 现象
AI Agent 发送的消息在服务器日志显示成功，但客户端看不到

### 原因
WebSocket 消息解析逻辑检查 `type == 'message'`，但服务器发送的 `WsMessage` 格式中 `type` 字段是消息类型（如 "text"），不是 "message"。

### 修复
更新 `_handleMessage` 方法，正确识别服务器发送的消息格式：

```dart
// 服务器发送的消息类型
final isTextMessage = type == 'text' || type == 'image' || type == 'video' || type == 'emoji';
final hasContent = json.containsKey('content');
final hasId = json.containsKey('id');

if ((isTextMessage || hasContent) && hasId) {
  final message = Message.fromJson(json);
  _messageController.add(message);
}
```

- `client/lib/data/services/websocket_service.dart`

## 服务器消息格式说明

### 数据库格式 (Message)
```json
{
  "id": "uuid",
  "sender_id": "uuid",
  "receiver_id": "uuid | null",
  "group_id": "uuid | null",
  "msg_type": 0,  // int: 0=text, 1=image, 2=video, 3=emoji
  "content": "string",
  "timestamp": 1234567890123,  // milliseconds
  "is_ai_generated": false,
  "delivered": false,
  "created_at": "2025-12-07T10:00:00Z"
}
```

### WebSocket 客户端格式 (WsMessage)
```json
{
  "id": "uuid-string",
  "conversation_id": "uuid-string",
  "sender_id": "uuid-string",
  "sender_name": "string | null",
  "sender_avatar": "string | null",
  "type": "text",  // string: text, image, video, emoji
  "content": "string",
  "status": "sent",
  "created_at": "2025-12-07T10:00:00+00:00"  // ISO 8601
}
```

### 客户端 Message.fromJson 兼容处理
- `conversation_id` 或 `group_id` 或 `receiver_id` → `conversationId`
- `type` (string) 或 `msg_type` (int) → `type`
- `created_at` (ISO string) 或 `timestamp` (milliseconds) → `createdAt`

## 问题6: 消息类型映射不匹配

### 现象
服务器发送的 emoji 类型消息可能无法正确解析

### 原因
服务器的 `MsgType` 枚举定义：
- 0 = Text
- 1 = Image
- 2 = Video
- 3 = Emoji

客户端原来的 `_msgTypeIntToString` 映射：
- 3 = audio ❌ (应该是 emoji)

### 修复
更新 `_msgTypeIntToString` 方法，与服务器保持一致：

```dart
static String _msgTypeIntToString(int msgType) {
  switch (msgType) {
    case 0: return 'text';
    case 1: return 'image';
    case 2: return 'video';
    case 3: return 'emoji';  // 修复：服务器发送 Emoji=3
    default: return 'text';
  }
}
```

同时在 `_messageTypeFromString` 中添加 emoji 类型处理：

```dart
case 'emoji':
  // Server sends emoji type, treat as text for display
  return MessageType.text;
```
