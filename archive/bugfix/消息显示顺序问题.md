# 消息显示顺序问题

## 问题描述
消息记录显示的顺序不对。

## 问题分析

### 原始逻辑
1. **API 返回**：`ORDER BY timestamp DESC`（最新的在前）
2. **客户端处理**：`messages.reversed.toList()`（反转，变成最旧的在前）
3. **ListView 配置**：`reverse: true`（从底部开始显示）

### 问题
多次反转导致顺序混乱：
- API 返回：`[newest, ..., oldest]`
- 客户端反转后：`[oldest, ..., newest]`
- ListView reverse 显示：最旧的消息在底部（❌ 错误）

## 解决方案

### 正确的逻辑
1. **API 返回**：`ORDER BY timestamp DESC`（最新的在前）
2. **客户端处理**：不反转，保持原顺序
3. **ListView 配置**：`reverse: true`（从底部开始显示）

### 结果
- API 返回：`[newest, ..., oldest]`
- 客户端保持：`[newest, ..., oldest]`
- ListView reverse 显示：最新的消息在底部（✅ 正确）

## 修复内容

### 1. 移除 `loadMessagesFromApi` 中的反转
```dart
// 修改前
state = messages.reversed.toList(); // Reverse to show newest first

// 修改后
state = messages; // Keep API order (DESC)
```

### 2. 移除 `loadMessagesFromDatabase` 中的反转
```dart
// 修改前
state = messages.reversed.toList(); // Reverse to show newest first

// 修改后
state = messages; // Keep database order (DESC)
```

### 3. 保持 `_addMessage` 的逻辑
```dart
// 新消息添加到列表开头（正确）
state = [message, ...state];
```

```
    ↓

    ↓

    ↓
ListView (reverse: true): 
    Bottom: msg3 (newest) ✅
    Middle: msg2
    Top: msg1 (oldest)
```
