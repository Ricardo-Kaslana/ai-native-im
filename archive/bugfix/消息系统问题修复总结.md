# 消息系统问题修复总结

## 概述

本次修复解决了 AI Native IM 应用中消息系统的多个关键问题，包括服务器端群消息投递和客户端实时更新。

---

## 问题 1：AI Agent 群消息不显示给群组成员

### 现象
- AI Agent 发送消息到群组，服务器日志显示 `ack: Success`
- 但群组中的其他成员看不到该消息

### 原因
`MessageRouterImpl` 的 `route_to_group` 方法没有数据库连接池，无法查询群组成员列表。原实现只向消息发送者（AI Agent）投递消息。

### 解决方案
1. 添加 `pool: Option<sqlx::PgPool>` 字段到 `MessageRouterImpl`
2. 添加 `with_pool()` 方法设置数据库连接池
3. 添加 `get_group_members()` 方法查询群组成员
4. 修改 `route_to_group()` 遍历所有成员并向在线成员投递消息
5. 在 `main.rs` 中调用 `.with_pool(pool.clone())`

### 修改文件
- `server/src/services/message/message_router.rs`
- `server/src/main.rs`

## 问题 2：群消息无法实时更新

### 现象
- 消息可以被接收，但不实时显示
- 需要登出再登入才能看到新消息

### 原因
1. **数据库实例不一致**：`message_provider.dart` 创建了新的 `AppDatabase()` 实例，而不是使用用户登录后的数据库
2. **Stream 实例不共享**：`messagePersistenceServiceProvider` 和 `globalPersistenceServiceProvider` 是独立实例
3. **消息监听架构问题**：`MessagesNotifier` 只在聊天界面打开时才监听消息

### 解决方案

#### 1. 修复数据库实例 (`message_provider.dart`)
```dart
// 使用正确的 userDatabaseProvider
final messageRepositoryProvider = Provider<MessageRepository>((ref) {
  final db = ref.watch(userDatabaseProvider);
  if (db == null) {
    throw StateError('No user database available.');
  }
  return MessageRepository(webSocketService, db, apiClient);
});
```

#### 2. 统一 MessagePersistenceService 实例 (`chat_provider.dart`)
```dart
final messagePersistenceServiceProvider = Provider<MessagePersistenceService>((ref) {
  return ref.watch(globalPersistenceServiceProvider);
});
```

#### 3. 创建全局消息处理器 (`global_message_handler.dart`)
```dart
class GlobalMessageHandler {
  void start() {
    _messageSubscription = _repository.messageStream.listen(
      _handleIncomingMessage,
    );
  }
  
  Future<void> _handleIncomingMessage(Message message) async {
    await _persistenceService.persistIncomingMessage(message);
  }
}
```

#### 4. MessagesNotifier 双重监听
```dart
void _init() {
  // 监听持久化消息流
  _messageSubscription = persistenceService.messagePersistedStream.listen(_handlePersistedMessage);
  // 直接监听 WebSocket 作为备份
  _wsMessageSubscription = repository.messageStream.listen(_handleWebSocketMessage);
}
```

### 修改文件
- `client/lib/data/services/global_message_handler.dart` (新建)
- `client/lib/presentation/providers/message_provider.dart`
- `client/lib/presentation/providers/chat_provider.dart`
- `client/lib/presentation/screens/home_screen.dart`

## 架构改进

### 之前
```
WebSocket → MessagesNotifier (仅聊天界面打开时) → UI
            ↓
         错误的数据库实例
```

### 之后
```
                    ┌→ GlobalMessageHandler → 用户数据库
                    │                              ↓
WebSocket ──────────┤                    messagePersistedStream
                    │                              ↓
                    └→ MessagesNotifier (直接监听) → UI
```
