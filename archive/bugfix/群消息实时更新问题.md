# 群消息无法实时更新问题

## 问题描述

AI Agent 发送的群消息可以被群成员接收到，但无法实时更新显示。用户需要登出再登入才能看到新消息。

## 错误现象

1. AI Agent 发送消息到群组
2. 服务器成功投递消息到在线用户的 WebSocket 连接
3. 客户端 WebSocket 收到消息
4. 但消息不显示在聊天界面
5. 重新登录后消息才显示

## 根本原因

客户端架构存在多个问题：

### 问题 1：数据库实例不一致
`message_provider.dart` 中定义了一个 `databaseProvider`，它创建了一个新的 `AppDatabase()` 实例，而不是使用 `userDatabaseProvider`（用户登录后打开的数据库）。这导致消息被保存到错误的数据库。

### 问题 2：消息流监听架构问题
1. `MessagesNotifier` 是一个 `family` provider，每个 `conversationId` 创建一个独立实例
2. 只有当用户打开某个聊天界面时，对应的 `MessagesNotifier` 才会被创建并监听消息流
3. 当用户离开聊天界面时，`MessagesNotifier` 被销毁，不再监听
4. 此时如果收到新消息，没有任何组件在监听并持久化它

### 问题 3：Stream 实例不共享
`messagePersistenceServiceProvider` 和 `globalPersistenceServiceProvider` 是两个不同的 `MessagePersistenceService` 实例，它们的 `StreamController` 是独立的，导致消息无法在组件间传递。

## 解决方案

### 1. 修复数据库实例问题 (`message_provider.dart`)

```dart
// 删除错误的 databaseProvider
// final databaseProvider = Provider<AppDatabase>((ref) {
//   return AppDatabase();
// });

// 使用正确的 userDatabaseProvider
import 'database_provider.dart';

final messageRepositoryProvider = Provider<MessageRepository>((ref) {
  final webSocketService = ref.watch(webSocketServiceProvider);
  final db = ref.watch(userDatabaseProvider);  // 使用用户数据库
  final apiClient = ref.watch(apiClientProvider);
  
  if (db == null) {
    throw StateError('No user database available. User must be logged in.');
  }
  
  return MessageRepository(webSocketService, db, apiClient);
});
```

### 2. 统一 MessagePersistenceService 实例 (`chat_provider.dart`)

```dart
final messagePersistenceServiceProvider = Provider<MessagePersistenceService>((ref) {
  // 使用全局的 persistence service 以共享 stream
  return ref.watch(globalPersistenceServiceProvider);
});
```

### 3. 创建全局消息处理器 (`global_message_handler.dart`)

```dart
class GlobalMessageHandler {
  final MessageRepository _repository;
  final MessagePersistenceService _persistenceService;
  StreamSubscription<Message>? _messageSubscription;
  
  void start() {
    _messageSubscription = _repository.messageStream.listen(
      _handleIncomingMessage,
    );
  }
  
  Future<void> _handleIncomingMessage(Message message) async {
    await _persistenceService.persistIncomingMessage(message);
  }
}
```

### 4. MessagesNotifier 双重监听机制

```dart
void _init() {
  // 监听已持久化的消息流
  _messageSubscription = persistenceService.messagePersistedStream.listen(
    _handlePersistedMessage,
  );
  
  // 同时直接监听 WebSocket 消息作为备份，确保实时更新
  _wsMessageSubscription = repository.messageStream.listen(
    _handleWebSocketMessage,
  );
}
```

### 5. 在 HomeScreen 初始化时启动全局处理器

```dart
@override
void initState() {
  super.initState();
  WidgetsBinding.instance.addPostFrameCallback((_) {
    ref.read(globalMessageHandlerProvider);
    ref.read(webSocketManagerProvider.notifier).connect();
  });
}
```

## 架构改进

**之前的流程：**
```
WebSocket → MessagesNotifier (仅当聊天界面打开时) → UI
            ↓
         错误的数据库实例
```

**改进后的流程：**
```
WebSocket ─┬→ GlobalMessageHandler → 正确的用户数据库
           │                              ↓
           │                    messagePersistedStream
           │                              ↓
           └→ MessagesNotifier (直接监听) → UI
```

## 验证方法

1. 用户 A 和用户 B 都加入同一个群组
2. 用户 A 打开群聊界面，用户 B 在消息列表界面（不打开群聊）
3. 在群组中 @AI Agent 触发回复
4. 用户 A 应该能实时看到 AI Agent 的消息
5. 用户 B 打开群聊界面，应该能看到 AI Agent 的消息
