# 群组成员列表不显示问题

## 问题描述

在客户端群聊信息页面中，无法显示群成员列表。

## 根本原因

**位置**：`client/lib/data/repositories/group_repository.dart` - `_groupMemberFromJson` 方法

**原因**：
- 后端 `GroupMemberInfo` 返回扁平结构：
  ```json
  {
    "user_id": "uuid",
    "username": "string",
    "avatar_url": "string",
    "role": "owner|admin|member",
    "is_muted": false,
    "online": true,
    "joined_at": "2024-12-06T..."
  }
  ```

- 客户端 `_groupMemberFromJson` 期望嵌套结构：
  ```dart
  user: User(
    id: json['user']['id'] as String,
    username: json['user']['username'] as String,
    // ...
  )
  ```

- 尝试访问 `json['user']['id']` 时失败，因为 `json['user']` 不存在

## 后端数据结构

**文件**：`server/src/models/group.rs`

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct GroupMemberInfo {
    pub user_id: Uuid,
    pub username: String,
    pub avatar_url: Option<String>,
    pub role: MemberRole,
    pub is_muted: bool,
    pub online: bool,
    pub joined_at: DateTime<Utc>,
}
```

**SQL 查询**：`server/src/services/group/member_service.rs`

```rust
let members = sqlx::query_as!(
    GroupMemberInfo,
    r#"
    SELECT 
        gm.user_id,
        u.username,
        u.avatar_url,
        gm.role as "role: MemberRole",
        gm.is_muted,
        (u.online_status = 'online') as "online!",
        gm.joined_at
    FROM group_members gm
    INNER JOIN users u ON gm.user_id = u.id

            WHEN 'owner' THEN 1 
            WHEN 'admin' THEN 2 
            ELSE 3 
        END,
        gm.joined_at ASC

    group_id,
    limit,
    offset
)
.fetch_all(&self.pool)
.await?;
```

## 解决方案

**文件**：`client/lib/data/repositories/group_repository.dart`

**修改前**：
```dart
GroupMember _groupMemberFromJson(Map<String, dynamic> json) {
  return GroupMember(
    id: json['id'] as String,
    groupId: json['group_id'] as String,
    user: User(
      id: json['user']['id'] as String,  // ❌ json['user'] 不存在
      username: json['user']['username'] as String,
      email: json['user']['email'] as String?,
      avatarUrl: json['user']['avatar_url'] as String?,
      bio: json['user']['bio'] as String?,
      isOnline: json['user']['is_online'] as bool? ?? false,
      createdAt: DateTime.parse(json['user']['created_at'] as String),
    ),
    role: _parseGroupRole(json['role'] as String),
    isMuted: json['is_muted'] as bool? ?? false,
    mutedUntil: json['muted_until'] != null
        ? DateTime.parse(json['muted_until'] as String)
        : null,
    joinedAt: DateTime.parse(json['joined_at'] as String),
  );
}
```

**修改后**：
```dart
GroupMember _groupMemberFromJson(Map<String, dynamic> json) {
  // Backend returns flat structure: user_id, username, avatar_url, role, is_muted, online, joined_at
  return GroupMember(
    id: json['user_id'] as String, // Use user_id as member id
    groupId: json['group_id'] as String? ?? '', // group_id might not be in response
    user: User(
      id: json['user_id'] as String,
      username: json['username'] as String,
      email: null, // Not included in GroupMemberInfo
      avatarUrl: json['avatar_url'] as String?,
      bio: null, // Not included in GroupMemberInfo
      isOnline: json['online'] as bool? ?? false,
      createdAt: DateTime.now(), // Not included in GroupMemberInfo, use current time
    ),
    role: _parseGroupRole(json['role'] as String),
    isMuted: json['is_muted'] as bool? ?? false,
    mutedUntil: json['muted_until'] != null
        ? DateTime.parse(json['muted_until'] as String)
        : null,
    joinedAt: DateTime.parse(json['joined_at'] as String),
  );
}
```

## 字段映射

| 后端字段 | 客户端字段 | 说明 |
|---------|-----------|------|
| `user_id` | `user.id` | 用户 ID |
| `username` | `user.username` | 用户名 |
| `avatar_url` | `user.avatarUrl` | 头像 URL |
| `online` | `user.isOnline` | 在线状态 |
| `role` | `role` | 角色（owner/admin/member） |
| `is_muted` | `isMuted` | 是否被禁言 |
| `joined_at` | `joinedAt` | 加入时间 |
| - | `user.email` | 后端未返回，设为 null |
| - | `user.bio` | 后端未返回，设为 null |
| - | `user.createdAt` | 后端未返回，使用当前时间 |
