# Flutter 客户端群聊创建问题修复

## 问题描述
Flutter 客户端无法正常创建群聊，报错：
```
❌ ERROR[500] => /groups
Message: Missing request extension: Extension of type `uuid::Uuid` was not found.
```

## 根本原因
1. **后端模型缺少字段**：`CreateGroup` 结构体缺少 `member_ids` 字段
2. **后端逻辑不完整**：`create_group` 函数只添加了群主，没有处理初始成员列表
3. **认证中间件不匹配**：群组 API 使用 `Extension<Uuid>` 提取用户 ID，但 JWT 中间件设置的是 `Extension<UserContext>`

## 修复内容

### 1. 修复认证中间件问题 (`server/src/api/groups.rs`)
将所有群组 API 函数从使用 `Extension<Uuid>` 改为使用 `Extension<UserContext>`：

```rust
// 修改前
Extension(user_id): Extension<Uuid>

// 修改后
use crate::middleware::UserContext;
Extension(user_ctx): Extension<UserContext>
// 使用 user_ctx.user_id 访问用户 ID
```

这样与 JWT 中间件设置的 Extension 类型一致。

### 2. 更新后端模型 (`server/src/models/group.rs`)
在 `CreateGroup` 结构体中添加 `member_ids` 字段：
```rust
pub struct CreateGroup {
    pub name: String,
    pub description: Option<String>,
    pub avatar: Option<String>,
    pub is_public: Option<bool>,
    pub member_ids: Option<Vec<Uuid>>,  // ✅ 新增
}
```

### 3. 更新群组创建服务 (`server/src/services/group/group_service.rs`)
在 `create_group` 函数中添加初始成员处理逻辑：
```rust
// Add initial members if provided
if let Some(member_ids) = request.member_ids {
    for member_id in member_ids {
        // Skip if member is the owner
        if member_id == owner_id {
            continue;
        }

        // Add member with 'member' role
        sqlx::query!(
            r#"
            INSERT INTO group_members (group_id, user_id, role)
            VALUES ($1, $2, 'member')
            ON CONFLICT (group_id, user_id) DO NOTHING
            "#,
            group.id,
            member_id
        )
        .execute(&mut *tx)
        .await?;
    }

    // Update member count
    let member_count = sqlx::query_scalar!(
        "SELECT COUNT(*) FROM group_members WHERE group_id = $1",
        group.id
    )
    .fetch_one(&mut *tx)
    .await?
    .unwrap_or(1);

    sqlx::query!(
        "UPDATE groups SET member_count = $1 WHERE id = $2",
        member_count as i32,
        group.id
    )
    .execute(&mut *tx)
    .await?;
}
```

## 问题 2: 群组创建成功但找不到

### 问题描述
用户创建群组成功后，在消息列表中找不到创建的群组。

### 根本原因
消息列表的 `conversationsProvider` 只获取私聊会话，没有包含群组。

### 解决方案
修改 `client/lib/presentation/providers/conversation_provider.dart`：
1. 创建 `_privateConversationsProvider` 获取私聊会话
2. 修改 `conversationsProvider` 合并私聊会话和群组
3. 将群组转换为 Conversation 对象
4. 按最后活动时间排序

```dart
/// Combined conversations provider - includes both private chats and groups
final conversationsProvider = FutureProvider<List<Conversation>>((ref) async {
  // Get private conversations
  final privateConversations = await ref.watch(_privateConversationsProvider.future);
  
  // Get groups and convert to conversations
  final groupsAsync = ref.watch(groupsProvider);
  final groups = await groupsAsync.when(
    data: (groups) => groups,
    loading: () => <Group>[],
    error: (_, __) => <Group>[],
  );
  
  // Convert groups to conversations
  final groupConversations = groups.map((group) {
    return Conversation(
      id: group.id,
      type: ConversationType.group,
      name: group.name,
      participants: [],
      lastMessage: null,
      unreadCount: 0,
      lastActivityAt: group.updatedAt ?? group.createdAt,
      createdAt: group.createdAt,
    );
  }).toList();
  
  // Combine and sort by last activity
  final allConversations = [...privateConversations, ...groupConversations];
  allConversations.sort((a, b) => b.lastActivityAt.compareTo(a.lastActivityAt));
  
  return allConversations;
});
```

## 问题 3: Flutter 编译错误

### 错误信息
```
error GC2F972A8: The argument type 'DateTime?' can't be assigned to the parameter type 'DateTime'.
error G7AD6136F: Method 'compareTo' cannot be called on 'DateTime?' because it is potentially null.
```

### 根本原因
`Conversation.lastActivityAt` 是可选类型 `DateTime?`，在排序时直接调用 `compareTo` 会导致空指针错误。

### 解决方案
修改排序逻辑，处理 null 值：

```dart
// 修改前
allConversations.sort((a, b) => b.lastActivityAt.compareTo(a.lastActivityAt));

// 修改后
allConversations.sort((a, b) {
  final aTime = a.lastActivityAt ?? a.createdAt;
  final bTime = b.lastActivityAt ?? b.createdAt;
  return bTime.compareTo(aTime);
});
```

如果 `lastActivityAt` 为 null，则使用 `createdAt` 作为排序依据。
