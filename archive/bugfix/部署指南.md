## 需要做的事情

### 1. 安装 PostgreSQL ⭐ 必需

**下载地址**: https://www.postgresql.org/download/windows/

**安装步骤**:
1. 下载 PostgreSQL 安装程序
2. 运行安装程序
3. 设置密码（例如：`postgres123`）- **记住这个密码！**
4. 保持默认端口 5432
5. 完成安装

**创建数据库**:

打开 CMD 或 PowerShell，运行：

```cmd
psql -U postgres
```

输入安装时设置的密码，然后在 psql 中执行：

```sql
CREATE USER dev_user WITH PASSWORD 'dev_password';
CREATE DATABASE ai_im_dev OWNER dev_user;
GRANT ALL PRIVILEGES ON DATABASE ai_im_dev TO dev_user;
\q
```

---

### 2. 启动 Redis ⭐ 必需

你已经安装了 Redis CLI，现在需要启动 Redis 服务器。

**方法 A: 如果已经安装了 Redis**

找到 `redis-server.exe` 并运行它。常见位置：
- `C:\Redis\redis-server.exe`
- `C:\Program Files\Redis\redis-server.exe`

**方法 B: 下载 Redis for Windows**

1. 访问: https://github.com/tporadowski/redis/releases
2. 下载最新版本（例如：Redis-x64-5.0.14.1.zip）
3. 解压到 `C:\Redis`
4. 运行 `C:\Redis\redis-server.exe`

**方法 C: 安装 Memurai (推荐，更稳定)**

1. 访问: https://www.memurai.com/get-memurai
2. 下载并安装
3. 自动作为 Windows 服务运行

---

### 3. 启动 Qdrant ⭐ 必需

**方法 A: 使用 Docker (最简单)**

```cmd
docker run -d -p 6333:6333 -p 6334:6334 --name qdrant qdrant/qdrant
```

**方法 B: 下载二进制文件**

1. 访问: https://github.com/qdrant/qdrant/releases
2. 下载 Windows 版本
3. 解压并运行 `qdrant.exe`

## 常见问题解决

### PostgreSQL 连接失败

```cmd
REM 1. 检查服务是否运行
services.msc

REM 2. 测试连接
set PGPASSWORD=dev_password
psql -U dev_user -d ai_im_dev -h localhost

REM 3. 如果提示 psql 不是命令，需要添加到 PATH
REM 通常在: C:\Program Files\PostgreSQL\xx\bin
```

### Redis 连接失败

```cmd
REM 1. 确保 redis-server.exe 正在运行
REM 2. 测试连接
redis-cli ping
REM 应该返回 PONG
```

### Qdrant 连接失败

```cmd
REM 使用 Docker
docker ps | findstr qdrant
docker start qdrant

REM 测试连接
curl http://localhost:6333/healthz
```

### 端口被占用

```cmd
REM 查找占用端口的进程
netstat -ano | findstr :8080

REM 结束进程
taskkill /PID <进程ID> /F
```

## 提示

### 使用 Docker 简化部署

如果你有 Docker Desktop，可以一键启动所有服务：

```cmd
docker compose up -d
```

这会自动启动 PostgreSQL、Redis 和 Qdrant。

### 加速 Cargo 编译

创建文件 `%USERPROFILE%\.cargo\config.toml`:

```toml
[source.crates-io]
replace-with = "aliyun"

[source.aliyun]
registry = "sparse+https://mirrors.aliyun.com/crates.io-index/"
```
