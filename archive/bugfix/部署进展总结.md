## 💡 关键经验

1. **Windows 部署的特殊性**
   - 需要特别注意路径和命令格式
   - PowerShell 和 CMD 的语法不同
   - JSON 在 CMD 中需要特殊处理

2. **前后端集成的关键点**
   - API URL 必须完全匹配
   - 响应格式必须一致
   - 字段名称必须匹配
   - 嵌套结构要正确处理

3. **调试技巧**
   - 添加详细的日志
   - 使用 curl 单独测试 API
   - 逐步排查问题
   - 查看完整的错误堆栈

4. **文档的重要性**
   - 详细的文档能大大加快问题解决速度
   - 脚本自动化能减少人为错误
   - 分步骤的指南更容易跟随
