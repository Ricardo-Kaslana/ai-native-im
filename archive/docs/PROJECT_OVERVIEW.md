# AI 原生极简即时通讯应用 - 项目总览

## 📋 项目简介

这是一个极致轻量、美观且跨平台的即时通讯应用，核心特色是深度集成的 AI Agent，提供"真实群友"般的智能聊天体验。应用遵循 Neo-Minimalism 设计理念，仅保留核心功能（通讯录、个人主页、私聊、群聊），追求极简、高性能和 AI 原生的用户体验。


### 核心理念

- **极简 (Minimalism)**: 大量留白、简洁设计、专注内容
- **AI 原生 (AI-Native)**: 群聊中的智能 AI Agent，具备记忆、个性和主动交互能力
- **高性能 (High Performance)**: 60/120fps 流畅体验、低延迟消息传递

### 目标平台

- iOS
- Android  
- Desktop (macOS/Windows/Linux)

### 技术栈

#### 后端 (Rust)
- **Web 框架**: Axum (轻量、高性能、基于 Tokio)
- **异步运行时**: Tokio
- **数据库 ORM**: SQLx (编译时 SQL 检查)
- **序列化**: Prost (Protobuf for Rust)
- **AI 集成**: reqwest (LLM API 调用), qdrant-client (向量数据库)

#### 前端 (Flutter)
- **框架**: Flutter (Latest Stable)
- **状态管理**: Riverpod
- **本地数据库**: Drift (SQLite ORM) 或 Isar (高性能 NoSQL)
- **网络**: web_socket_channel (WebSocket), dio (HTTP)
- **序列化**: protobuf (Dart)
- **媒体**: ffmpeg_kit_flutter, flutter_image_compress

#### 基础设施
- **主数据库**: PostgreSQL
- **缓存/消息队列**: Redis (会话缓存、Pub/Sub)
- **向量数据库**: Qdrant 或 Pgvector (AI 长期记忆)
- **对象存储**: S3 + CloudFront CDN
- **通讯协议**: Protocol Buffers v3
