## 💰 时间节省计算

假设每天运行测试 10 次：

### 之前
```
10 次 × 300秒 = 3000秒 = 50 分钟/天
```

### 之后（使用 nextest）
```
10 次 × 45秒 = 450秒 = 7.5 分钟/天
```

### 节省时间
```
50 - 7.5 = 42.5 分钟/天
212.5 分钟/周
850 分钟/月 ≈ 14 小时/月 🎉
```
